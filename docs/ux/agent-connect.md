# 交互规格：Agent 接入（外部 Agent 接入 (MCP) 弹窗）

> 项目：/Users/teaxus/AILearning/ai-cut　日期：2026-10-25　作者：主会话（Opus 5.5）
> 取代上游的「外部 Agent 接入 (MCP)」弹窗（`src/components/settings/McpGuide.tsx`），入口不变：
> 首页顶栏与编辑器顶栏的插头按钮（两处都经 `mcpGuideLoader.ts` 加载，派生版只改这一个加载器 → 接入点 IP-16）。
> 实现：`src/components/aicut/agent-connect/`（入口 `McpGuide.tsx`）。

## 1. 用户与目标
- 谁用：装了 AI Cut、同时在用 Claude Code / Codex / Cursor 等 AI 编码 agent 的人。频率低：装好 AI Cut 后一次，换端口 / 新装 agent / 升级 AI Cut 后偶尔一次。
- 来做什么：让自己的 agent 能直接操作 AI Cut 剪视频——agent 里要有 AI Cut 的 MCP 服务（带令牌）和 `ai-cut` 技能。
- 做成的标志：每个检测到的 agent 行上「MCP：已安装」「技能：已安装」；重开 agent 后它能调用 `openchatcut_status`。

## 2. 入口与对象
- 入口：顶栏插头按钮 → 弹窗（与上游同一位置、同一标题「外部 Agent 接入 (MCP)」）。不新增入口。
- 对象：本机检测到的每个 agent（一行一个）。对象名（agent 名 + logo）在行首常显。
- 打开即自动检测（反模式 76）：弹窗一打开就请求状态列表；右上角「重新检测」图标按钮（带悬停提示），装完新 agent 不用关窗。

## 3. 主路径
| 步 | 用户看到 | 用户做 | 系统反馈 |
|---|---|---|---|
| 1 | 标题、端点地址；下面「正在检测本机的 agent…」 | — | 列表出现：检测到的 agent 按「需要处理 → 已全部装好」排序 |
| 2 | 每行：logo、名称、「检测到：~/.claude」；两个状态标签「MCP：未安装」「技能：未安装」；标签下一行小字写清**会写到哪**（`~/.claude.json` 的 ai-cut 项、`~/.claude/skills/ai-cut/`）；行尾主按钮「安装」 | 点某行「安装」 | 按钮变「安装中…」；完成后该行两个标签就地变成「已安装」，行尾显示「已安装 ✓」与「卸载」；失败时行内红字写原因（例如「~/.cursor/mcp.json 不是有效 JSON，为避免覆盖未写入」） |
| 2' | 列表上方汇总条：「检测到 N 个 agent，其中 M 个需要安装或更新」+ 主按钮「全部安装 / 更新（M）」；按钮下小字「将修改 M 个配置文件、复制 K 份技能；改动前原文件备份到 ~/.ai-cut/agent-backups/」 | 点「全部安装 / 更新」 | 逐个执行，按钮显示进度「安装中 3/5」；结束后各行就地更新，汇总条显示「完成 5 个」或「完成 4 个，失败 1 个（见红字行）」 |
| 3 | 底部提示「装好后重启对应的 agent 才会加载 AI Cut」 | 去 agent 里用 | — |

高频动作：「全部安装 / 更新」1 步；单个 agent「安装」1 步。

## 4. 状态矩阵
| 状态 | 长什么样 | 用户能做什么 |
|---|---|---|
| 加载中 | 列表区一行「正在检测本机的 agent…」 | 等 |
| 读取失败 | 列表区红字「检测失败：<原因>」+「重试」按钮 | 重试 |
| 令牌读不到 | 沿用上游文案「无法读取 MCP 连接令牌，请从受信任的编辑器窗口重试。」 | 关窗重开 |
| 空（一个都没检测到） | 「本机没有检测到支持的 agent」+ 下面直接展开「支持的 agent」清单（名称 + 是否能自动安装） | 装好 agent 后点「重新检测」 |
| 某行：需更新 | 标签「MCP：需更新」+ 原因小字「地址或令牌与当前 AI Cut 不一致」；主按钮「更新」 | 更新 |
| 某行：只能手动 | 标签「MCP：需手动添加」+ 原因小字（「配置文件带注释，App 不改它」/「这个 agent 的配置格式还没核实」）；配置片段 `<pre>` 直接展开显示；按钮「复制配置」 | 复制后去 agent 里粘贴；技能部分仍可「安装」 |
| 某行：不支持远程 MCP | 标签「MCP：不支持」+ 小字「这个 agent 只支持本地命令行 MCP」 | 只装技能 |
| 某行：技能目录被占 | 标签「技能：同名目录不是 AI Cut 装的」+ 小字写路径 | 不覆盖；用户自行处理 |
| 某行：读不懂配置 | 标签「MCP：配置文件读不懂」+ 原因 + 路径 | 修好文件后「重新检测」 |
| 批量部分失败 | 汇总条「完成 4 个，失败 1 个」；失败行红字原因 | 修好后对失败行单独「安装」 |

## 5. 完整性
| 对象 | 建 | 改 | 删 | 撤销 | 导入/导出 | 批量 |
|---|---|---|---|---|---|---|
| agent 里的 ai-cut MCP 项 | 安装 | 更新 | 卸载（确认） | 原文件已备份到 ~/.ai-cut/agent-backups/<时间>/（确认框里写明）；重新安装即恢复 | 不适用（配置在 agent 自己的文件里） | 全部安装 / 更新 |
| agent 里的 ai-cut 技能目录 | 安装 | 更新 | 卸载（确认） | 重新安装即恢复（技能来自 AI Cut 自带文件） | 不适用 | 同上 |

## 6. 破坏性与离开上下文的动作
| 动作 | 后果 | 点之前用户看到什么 | 能撤销吗 |
|---|---|---|---|
| 安装 / 更新 | 改 agent 的配置文件（只加 / 改 ai-cut 一项）、复制技能目录 | 行内写明目标文件与目录；批量按钮下写明改几个文件、备份到哪 | 卸载即可；原文件有备份 |
| 卸载 | 从配置文件删掉 ai-cut 一项、删除 AI Cut 装的技能目录 | 行内二次确认：「将从 ~/.claude.json 删除 ai-cut 项，并删除 ~/.claude/skills/ai-cut/。改动前会备份配置文件。」+「确认卸载」「取消」 | 重新安装 |
| 复制配置 | 写剪贴板 | 片段已展开可见 | — |
| 文档链接（每行的「来源」） | 系统浏览器打开官方文档 | 链接文字「配置说明」，悬停显示完整地址 | — |

## 9. 明确不做
- 不做「仍要安装」到没检测到的 agent（反模式 13）：没装的 agent 写了也没用，只在折叠区列出支持情况。
- 不做项目级（某个代码仓库里的 .claude/ 等）安装：AI Cut 是全局工具，项目级由 agent 自己管理。
- 不在界面里编辑 agent 的其他配置。
- 不保留上游的逐客户端「连接」按钮（被本弹窗的「安装」取代，避免两套做同一件事的按钮，反模式 4）。上游弹窗下半部分的两张说明卡（内置 Agent 与外部 MCP、连接本地模型）和令牌说明原样保留。
